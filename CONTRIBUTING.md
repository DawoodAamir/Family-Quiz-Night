# Contributing

Use Xcode 27 and Swift 6. Keep code changes focused and commit messages concise, such as `fix: reject answers from a previous round`.

Run core tests in Debug and Release and the relevant native UI workflow. Add tests for changes to game rules, message bounds, session identity, deadlines, or reconnection. Keep question wording original and explain every correct answer. Avoid new dependencies without a clear need.

Never put personal signing details, private media, production credentials, or real player information in commits or screenshots. For networking changes, also check Local Network denial, duplicate room names, controller sleep/wake, host termination, and LAN interruption on physical devices. Describe which checks you actually performed.
